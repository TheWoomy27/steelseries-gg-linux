Set up SteelSeries GG

gg-linux runs SteelSeries GG's own client, taken from GG's Windows installer. Nothing from SteelSeries comes with gg-linux, so it needs that installer once.

GG's installer

Download it from steelseries.com (about 430 MB), or use one you have. gg-linux unpacks the parts it needs into your home folder.

Device access

A udev rule lets your user talk to SteelSeries devices, play macros and turn mouse motion. Installing it asks for your password.

Recording macros in GG reads your keyboard and mouse, which needs the input group (it can read all keyboards). To allow it, run then log in again.
